# My Description

Random objects like houses, fake dogs, plants, etc., are held together by colored screws. The game tells you which color of screws you need to pull out. For example, there's a place to hold three red screws, and you rotate this three-dimensional object to find all three visible red bolts, and you click on those, and then they go back into that box. Once that box is full, it gives you a new color of screws to find. As you pull screws out of these three-dimensional objects, different sections fall away off the screen, and the goal is to entirely disassemble the 3D object. The hard part is that some screws are hidden by different sections of the three-dimensional object, so you've got to pull screws in a certain order in order to expose the next set of screws.
